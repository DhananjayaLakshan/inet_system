# Employee Visit & Asset Management System

A comprehensive web application to manage employee work tracking, company visits, expenses, and IT asset management.

## 🚀 Built With

- **Framework**: Laravel 12
- **Authentication**: Laravel Breeze
- **Frontend**: Blade Components & Tailwind CSS
- **Hosting**: cPanel
- **Design**: Mobile-responsive interface

## 📋 Key Features

### 👥 Employee Visit Management
- **Weekly Visit Tracking**: Employees can log their company visits through personalized dashboards
- **Real-time Dashboard**: Live updates showing current week's visit statistics
- **Visit Details**: Track visit purposes, activities performed, and remaining companies to visit
- **Team Visibility**: All employees and admins can view updated visit information

### 💰 Automated Expense Management
- **Auto-generated Expenses**: Weekly visits automatically populate individual expense tables
- **Expense Tracking**: Employees fill in expenses and visit routes for each company visit
- **Individual Records**: Separate expense tracking for each employee

### 🖥️ IT Asset & Service Management
- **Service Records**: Track laptop and desktop maintenance history
- **Service Reminders**: Automated notifications to admins one week before next service date
- **Software Inventory**: Record installed software and operating systems
- **Component Tracking**: Monitor hardware upgrades (RAM, hard drives, etc.) with timestamps and employee details

### 🔍 Advanced Filtering & Reporting
- **Company Profiles**: Comprehensive view of all visits, software installations, and services per company
- **Detailed History**: Access complete company interaction history in one place

## 🎯 Purpose

This system streamlines field operations for IT support teams by:
- Automating visit and expense tracking
- Maintaining comprehensive asset service records
- Providing real-time visibility into team activities
- Ensuring timely maintenance through automated reminders

## 📱 User Experience
- Mobile-responsive design for on-the-go access
- Intuitive interface for easy management
- Secure authentication system
- Efficient data entry and retrieval
